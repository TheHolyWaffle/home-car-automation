home-car-automation · last updated 28 October 2026

What this is

home-car-automation is a personal, non-commercial, self-hosted hobby project by Bert De Geyter (private individual). It automates one privately owned car through the Volvo Cars Connected Vehicle API. It is not affiliated with or endorsed by Volvo Cars, and it is not offered as a service to other users.

What it does

  • Starts the engine on a user-defined schedule to precondition the cabin.
  • Locks the car when it has been left unlocked, closed and unused for a set time.
  • May use the car's location to only run these automations when it is parked at home.

Data

To decide when to act, the service reads door, lock, odometer, engine status and location data. These values are only held in memory and are not stored, logged in bulk or shared with anyone. The only thing persisted is the OAuth token, on the owner's own machine. You can revoke access at any time from your Volvo ID account.
